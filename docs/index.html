05 Safe by design

Change one version.
Keep the rest.

dsm is careful with your machine, so you can be fast without being reckless.

Version pinning

Every other installed version is pinned before an install or uninstall, so dotnetup's cleanup only touches the one you picked.

Lifecycle at a glance

Every row is tagged 🍀 active, 🏭 preview, 🚧 maintenance or 👿 end-of-life — no release notes required.

Self-updating

dsm tells you when a new release is out. Press Ctrl+U and it updates itself in place.

Dark & light

Press F6 to switch themes. The terminal background adapts for a native look in both.
